# 🚗 Car Price Prediction Using Machine Learning


This project predicts the selling price of used cars using Machine Learning techniques.  
It uses features like year, present price, fuel type, and transmission to estimate the price.
Used number for Car_names to maintain privacy.


## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn


## 🧠 Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Encoding (One-Hot Encoding)
4. Feature Scaling (StandardScaler)
5. Model Training
6. Model Evaluation
7. Prediction

## 🤖 Model
-  Random Forest Regressor - To deal with complex models
